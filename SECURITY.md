# Политика безопасности (Security Policy)

## Поддерживаемые ветки

Обновления и исправления применяются к следующим веткам репозитория `dyastrebov-lab/lab02`:

| Ветка     | Статус поддержки             |
| --------- | ---------------------------- |
| `master`  | Поддерживается (релизная)    |
| `develop` | Активная разработка          |

## Сообщение об уязвимости

Если вы обнаружили проблему безопасности или потенциально небезопасную конфигурацию в этом репозитории, пожалуйста, **не создавайте публичный Issue**.

Сообщите о проблеме приватным способом через GitHub Security Advisories:
- https://github.com/dyastrebov-lab/lab02/security/advisories/new

В сообщении желательно указать:
1. Описание проблемы и затронутый файл.
2. Шаги для воспроизведения.
3. Возможные последствия и рекомендации по исправлению (если есть).

Первичный ответ предоставляется в течение **48 часов** с момента обращения.

## Целостность кода

Все коммиты в репозитории подписываются GPG-ключом (`git commit -S`) и имеют статус **Verified** на GitHub.

## Примечание

Репозиторий создан в рамках выполнения лабораторной работы №2 («Linux: права доступа и процессы»). Файл `pygamesteel.py` намеренно содержит учебные ошибки из задания (исправленная версия находится в `pygamesteel_fixed.py`), а файлы `screen` и `nmapres.txt` используются для отработки практических шагов курса.
