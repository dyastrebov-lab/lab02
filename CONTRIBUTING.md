# Руководство по внесению изменений (Contributing)

Спасибо за интерес к репозиторию `dyastrebov-lab/lab02`! Ниже описаны основные правила работы с проектом.

## Настройка локального окружения

1. Склонируйте репозиторий и перейдите в ветку `develop`:
   ```bash
   git clone git@github.com:dyastrebov-lab/lab02.git
   cd lab02
   git checkout develop
   ```
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install pygame-ce
   ```

## Процесс внесения изменений

1. Создавайте ветку от актуальной `develop` (или работайте в отдельной тематической ветке):
   ```bash
   git checkout -b feat/short-description
   ```
2. Вносите изменения небольшими, логически завершёнными шагами (**атомарные коммиты**).
3. Подписывайте каждый коммит GPG-ключом (`git commit -S`) и используйте формат **Conventional Commits**:
   - `feat:` — новая функциональность или учебный скрипт
   - `fix:` — исправление ошибок
   - `docs:` — обновление документации (`README.md` и т.д.)
   - `chore:` — служебные изменения (`.gitignore`, метаданные репозитория)
4. Откройте Pull Request в ветку `develop` (финальное слияние в проекте выполняется по схеме `develop → master`).

## Стандарты

Участвуя в проекте, вы соглашаетесь соблюдать [Кодекс поведения](CODE_OF_CONDUCT.md) и распространять свой вклад под лицензией Apache License 2.0 (см. [LICENSE.md](LICENSE.md)).
